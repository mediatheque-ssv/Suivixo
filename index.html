Publier les modifications

Pour que l'équipe voie tes modifications, Suivixo a besoin d'une clé d'accès GitHub. Elle reste dans ce navigateur. Sans clé, tout se consulte mais rien n'est publié.

Créer une clé d'accès
  1. Connecte-toi à GitHub avec le compte mediatheque-ssv.
  2. Ouvre la création de clé.
  3. Accès : Only select repositories, puis Suivixo.
  4. Permissions : Contents, en Read and write.
  5. Génère la clé et colle-la ci-dessus.
