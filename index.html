Publier les modifications

Pour enregistrer les modifications dans le dépôt GitHub, Suivixo a besoin d'une clé d'accès. Elle reste dans ce navigateur. Sans clé, tu peux tout consulter et importer, mais rien n'est publié.

Créer une clé d'accès
  1. Connecte-toi à GitHub avec le compte mediatheque-ssv.
  2. Ouvre la création de clé « fine-grained ».
  3. Nom : « Suivixo », expiration : 1 an. Accès : Only select repositories → suivixo.
  4. Permissions du dépôt : Contents → Read and write. Rien d'autre.
  5. Génère la clé, copie-la et colle-la ci-dessous.
